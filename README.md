# 💡 Ideia Portfólio

Projeto de estudo focado em estruturação de página de portfólio — HTML, CSS e JavaScript.

## Sobre o projeto

Este repositório foi criado como exercício de construção de uma landing page de portfólio profissional — explorando seções como Hero, Sobre, Projetos em Destaque, Experiência Profissional e Contato. O conteúdo textual (nome, empresas, projetos) é fictício, usado como placeholder para focar no estudo da estrutura e do layout da página.

O objetivo central foi praticar:

- Estruturação de uma página de portfólio completa, com múltiplas seções
- Organização de layout com HTML semântico e CSS
- Interatividade com JavaScript (navegação, contadores animados, modais de experiência)
- Responsividade

## O que foi praticado

- Layout de página única (single page) com navegação por âncoras
- Seções de apresentação, projetos e experiência profissional
- Elementos interativos em JavaScript
- Estruturação visual de um portfólio profissional do zero
